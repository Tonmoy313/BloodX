## P1 — Donor identity and readiness
Read: spec/donor.md (and spec/auth.md for P1-5).

- [ ] **P1-2** Versioned readiness questionnaire from server; check stored with version + time; valid 24 h
- [ ] **P1-3** Eligibility service (cooldown, deferral, readiness validity, availability, quiet hours)
- [ ] **P1-4** Profile screen (next-eligible date, history placeholder)
- [ ] **P1-5** In-app account deletion (both platforms)
- [ ] **P1-6** Language switch bn/en, persisted
- [ ] **P1-8** Opt-in donor mode: unchecked box at sign-up, "Become a donor" card, "Leave donor mode"
- [ ] **P1-9** Availability: modes, auto-expiry (7/30 days), quiet hours, single expiry prompt + (7/30/60/90)-day snooze option. Always starts in an 'off' state.
- [ ] **P1-10** Server-side validation for all inputs, debounced area search, skeleton screens.
Exit conditions: Cooldown boundary test (male/female), deferral, expired readiness status. Availability is set to 'off' following setup, cooldown, deferral, or a break. Expiry prompt triggers once; includes 'snooze' and 'silence' options. Deletion ensures anonymity; responses are never logged.
