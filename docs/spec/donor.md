# donor — opt-in, profile, readiness, availability, eligibility
Entities: DonorProfile(user_id unique, full_name, date_of_birth, sex, blood_group, last_donated_at (self-declared until a confirmed donation replaces it), donor_status, availability_mode (always starts off), available_until, quiet_hours_start/end, critical_override, reminders_opt_in (default false), last_prompt_at, prompt_snooze_until, notification_paused_until, total_confirmed_donations) · Area(id, name_en, name_bn, city, active) · AreaAdjacency(area_id, neighbor_area_id) · DonorArea(donor_id, area_id; ≤3) · ReadinessQuestionnaire(id, version, localized questions, active_from) · ReadinessCheck(donor_id, version, answers, passed, created_at, valid_until) · Deferral(donor_id, category, source, starts_at, ends_at, needs_admin_review, pledge_id?, created_at; no free text).
Indexes: DonorProfile(blood_group, donor_status, availability_mode, available_until) · DonorArea unique(donor_id, area_id) + (area_id) · ReadinessCheck(donor_id, valid_until) · Deferral(donor_id, ends_at).
Endpoints: becomeDonor[user] · leaveDonorMode · getMyProfile · saveProfile · setReachableAreas(≤3) · setAvailability(mode, duration 7|30|90) · setQuietHours(start, end, critical_override) · respondAvailabilityPrompt(stay(duration) | not_now) · submitReadinessCheck(version, answers) → passed, valid_until, deferral if failed · getEligibility → eligible, reasons, next_eligible_at · getReadinessQuestions · getAreas · searchHospitals.
Rules:
- Any user can request blood. Donor mode is opt-in (D-015): checkbox unchecked by default at sign-up, or "Become a donor" card (Home, Profile). Checking only starts setup. donor_status: none → setup_incomplete → active → left. "Leave donor mode" any time: removed from matching at once, history kept.
- Availability (D-016): starts Off and returns to Off after setup, cooldown ending, deferral ending, break rule. The system never switches it on. Donor picks mode (Off | Critical only | All) + duration (7/30/90 d; 30 pre-highlighted only after choosing a mode other than Off); auto-expires. At expiry ONE prompt (S24); "Not now" or silence = Off + no prompt for 90 d. "Tell me when I'm eligible again" only if the donor enabled it. Declining or ignoring an alert has no consequence and is not recorded. Quiet hours on by default for non-critical; critical alerts at night only with critical_override.
- Eligible for ALERTS: profile complete, donor_status active, mode≠off, available_until>now, mode allows the urgency (critical_only → CRITICAL only), outside quiet hours (unless critical + override), not past notification_paused_until, no active deferral (admin-review deferral blocks), now ≥ last_donated_at + cooldown(sex), age in range (**medical**).
- May PLEDGE (browsing and pledging are donor-initiated and work with availability Off, P-017): donor_status active, cooldown and deferral pass, readiness check passed within 24 h. Readiness gates the pledge button, not the list (P-003).
- last_donated_at updates only on a donation confirmed by both sides.
- Placeholder readiness questions (owner supplies final wording, D-014): I feel well today · no fever or infection now · no new medication or recent procedure · I have eaten and am hydrated. Footer: final eligibility is the hospital's decision. A failed answer → "Not eligible today" + hold date.
- Copy: never guilt, rush, or shame; no streaks, countdowns, leaderboards, "you haven't donated" messages; "Not now" is one tap with no consequence.
- Supply metric: available donors per hospital area; thin supply → honest wording to the requester + flag to admin.
Screens: S03 stepper (about you · health declaration · areas; availability stays Off) · S23 availability sheet (Off / Critical only / All; 7/30/90 d; quiet hours ☑ 22:00–07:00; ☐ critical during quiet hours; opens Off unless already set) · S24 expiry prompt ("Your availability ended. Stay available for 30 days? [Yes, 30 days] [Not now]"; neutral push text) · S13 readiness sheet · Home donor card: not donor → "Become a donor"; donor Off → "Not receiving alerts [Change]"; available → mode + expiry; never nags · S16 Profile (donor card, next eligible, history, areas) · S20 Settings (language, notifications, privacy, leave donor mode, delete account).
Tests: box unchecked by default · becomeDonor never sets availability · Off after setup/cooldown/deferral/break · expiry, single prompt, snooze/silence · critical_only gets only critical · quiet hours + override · Off donor can browse and pledge but gets no alerts · declining records nothing · leaving removes from matching at once · cooldown boundaries M/F (day before, of, after) · expired readiness blocks pledge, not list · deferral and admin-review block · answers and categories never in logs.
